# WorkflowKit 1.0.0

將 GitLab Workspace 的工作流程整合包拆為獨立 Repo 與 Release，包含 Codebase LLM Wiki 0.6.4、MergeReviewer 0.19.0、ReleaseReviewer 0.8.0 及 Output Style。

- 完整 ZIP 附獨立安裝器；解壓後可使用 `python install.py --target <資料夾>`，不需要安裝 Extension。
- 同一套驗證與交易安裝支援 Group／Repository profile、預檢、重複安裝及 rollback。
- 納入正式 GitLab Workspace 0.32.0 的發布附件及安裝器，作為可信升級基線；保留既有歷史遷移測試。
- 提供 `release.json` 與 SHA-256，供 GitLab Workspace 0.33.0+ 選擇最新相容正式版並下載安裝。
- 提供 Gitea 鏡像命令，於公司內網複製相同 tag、附件與摘要。

本版延續現有 Skills 行為與上游版本。套件拆分、安裝與來源驗證不代表重新評定上游審查模型的品質或效能。
