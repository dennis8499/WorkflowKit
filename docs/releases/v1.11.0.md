# 1.11.0

整合 MergeReviewer 0.23.0 的續讀狀態、checkpoint revision 與 schema 能力。固定啟動器新增綁定 schema 動作及精確純讀 help 入口，持續驗證原 request SHA、安裝來源及 payload 身份。

啟動器以 stderr JSONL 回報驗綁定、capabilities 與 child 的分段耗時，stdout 保持原生協定。可靠度 runner 可指定新一輪 baseline/candidate 身份 manifest；舊矩陣維持原意，正式耗時預設依序執行。

安裝及相容性使用正式整包與全新 request/binding 驗收；舊活動保留原安裝。GitlabWorkSpace 0.51.0 入口契約維持相容。模型品質與完整模型時間須有對應實跑收據，不以 helper 重播替代；歷史候選驗證紀錄保留其原版本、摘要及驗證範圍。

本版同步收錄 Codebase LLM Wiki 0.7.4 與 ReleaseReviewer 0.12.2 的 Output Style 明確選用規則。上游來源使用對應正式 Release 的原始附件，並核對來源 Commit、套件內容及 SHA-256。
