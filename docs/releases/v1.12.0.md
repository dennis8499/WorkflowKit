# 1.12.0

整合 MergeReviewer 0.24.0。新版報告新增摘要與檢查紀錄，支援問題導航和證據收合。大型審查可將產生的分頁請求檔直接交給唯讀查詢，以相同的固定來源繼續讀取。[MergeReviewer 0.24.0 發行說明](https://github.com/dennis8499/MergeReviewer/releases/tag/v0.24.0)

啟動器核對請求綁定與安裝內容後，可直接使用套件內的能力描述。新請求會鎖定新版 Reviewer。請在原安裝上完成或停止舊請求後再原位升級，避免破壞原有綁定。

支援從 WorkflowKit 1.11.0 正式版升級與回復，涵蓋 Group、Repository 各自的內建及外部 BMAD 模式。安裝與狀態查詢沿用 Workspace Contract 2、Installer API 1 和 Status API 1。
