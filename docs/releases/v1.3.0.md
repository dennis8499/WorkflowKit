# WorkflowKit 1.3.0

Upgrade the bundled Codebase LLM Wiki from 0.6.4 to 0.7.0 and add the explicit `visualize` capability to Group and Repository profiles. The Group overlay keeps diagrams and their companion synthesis pages in the shared Wiki, with source citations written as `Repo/path`.

The package includes the pinned Archify 3.2.0 files and verifies them before use. Publishing a diagram requires Node.js 18+ and a local browser; the offline WorkflowKit installer still needs only Python 3.11+.

Updates recognize verified 1.2.0 and 1.2.1 installs for both profiles and both BMAD modes. User Wiki files, prior visualizations, reports, and BMAD customizations remain under the existing transaction and rollback rules.
