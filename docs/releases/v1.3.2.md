# WorkflowKit 1.3.2

## ReleaseReviewer compatibility

This kit pins ReleaseReviewer 0.11.0 as its minimum compatible version and records the canonical helper payload SHA-256. The build checks both values against the frozen offline source before producing the kit. Workbench capability probes pass the installed payload hash to the helper and enable new operations only when their individual flags are present.

ReleaseReviewer retains the v3 context, draft, and report schemas. The kit continues to install its native skill payload without a workspace overlay.
