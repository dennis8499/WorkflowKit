# WorkflowKit 1.3.3

## ReleaseReviewer compatibility

This kit pins ReleaseReviewer 0.11.1 as its minimum compatible version and verifies the canonical helper payload SHA-256 against the frozen offline source before building. Workbench capability probes pass the installed payload hash to the helper and enable each operation only when its feature flag is present.

The pinned helper includes the active batching path for compatible case-sensitive literal searches. It retains the v3 context, draft and report schemas and installs as a native skill without a workspace overlay.
