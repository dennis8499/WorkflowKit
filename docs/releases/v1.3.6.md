# WorkflowKit 1.3.6

更新日期：2026-11-05。本版更新本機離線整合包，納入 MergeReviewer 0.20.6 與 ReleaseReviewer 0.12.0。

MergeReviewer 改善受管 runtime 的 Repo 掃描、刪除契約錨點、提前診斷與固定證據驗證進度，並包含 0.20.5 的報告發布重試、批次 artifact 續讀及工具身分資訊。ReleaseReviewer 改善 runtime 診斷、同 request 的發布重試、摘要預覽、批次唯讀續讀，以及本次變更新增 P0／P1 觸發條件的 base 證據要求。兩者均直接封裝原生 Skill，透過既有共用 runner 執行。

ReleaseReviewer 的最低版本與驗證 payload SHA-256 同步更新為 0.12.0 的實際內容。Codebase LLM Wiki 0.7.2、BMAD Method 6.12.4、Output Style 與現有 overlays 保留。

保存已驗證的 1.3.5 本機 ZIP、安裝器與校驗資料，新增 Group／Repository 各自 bundled／external BMAD 的四種可信升級身分。前版信任資料包含共用 runner，支援升級、重複安裝及 rollback；既有個人設定、Wiki、報告與 BMAD 自訂內容保留。

發行格式維持 `workflowkit-release/v1`、workspace contract 2、installer API 1 與 status API 1。正式發布須通過相同最終 commit 的 Windows／Python 3.11、3.14 CI 完整矩陣，並直接發布驗證過的附件。

本機 Windows／Python 3.14.7 驗證：來源附件檢查、最終產物驗證及 `scripts/test.py` 完整執行成功。安裝與整合回歸 137 項通過，2 項因 Windows 帳號缺少建立 symbolic link 的權限而略過；發行流程程式測試另有 25 項通過。實際驗證 18 個歷史版本升級／重複安裝／rollback 組合，包含 1.3.5 的四種 profile／BMAD 模式，並核對 native payload、批次續讀、同 request 發布重試與未完成結果保留。ZIP、兩份安裝器、manifest、`release.json` 與 `SHA256SUMS` 一致。

凍結來源時，兩個來源專案均只有未追蹤的 `.agents/` 目錄，來源快照如實記錄 dirty 狀態；該目錄不屬於封裝內容。整合測試只驗證來源、安裝與 helper 行為。上游三模型語意品質、完整 Agent 耗時與企業 runtime 身分／ACL 的獨立驗收仍未完成，不據此宣稱品質或效能改善。
