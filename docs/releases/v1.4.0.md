# WorkflowKit 1.4.0

新增 Model Routing，供 MergeReviewer、ReleaseReviewer 的直接 Skill 與 GitLab 工作台入口共用。以固定變更及必要上下文選擇 GPT-6 Luna low、medium、high、xhigh 或 max；一般程式變更預設 high。`effort=auto` 可隨具體新風險保存進度後提高強度，手動指定則固定。

Routing 使用一次原生 capture，保留同一 request、SHA、證據、草稿及升級 checkpoint。獨立紀錄於 Reviewer runtime 的 routing/，原生 context 清理後仍可讀取。工作台查詢模型目錄後以明確 model／effort 啟動各回合；缺少所需能力時保存進度並回報。原生報告及未完成審查語意維持既有契約。

Group、Repository 與 BMAD bundled／external 均包含新 Skill。新增 1.3.6 的已驗證升級指紋與回復 fixture；既有 Reviewer 固定來源沿用原封裝。維護 kit-owned 資源可執行 `scripts/workflow-kit-sources.py --freeze-workspace`，不需重新凍結上游。
