# WorkflowKit 1.5.0

Group 與 Repository profiles 新增 CommitReviewer 0.1.0，提供已暫存差異的 Commit 草稿與 MR 前檢查。來源固定為正式 Release 的提交、附件及檔案 SHA-256，其餘上游版本沿用 1.4.0。

新增 `commit-draft`、`mr-precheck` capabilities，沿用 workspace contract 2、installer/status API 1。CommitReviewer 使用原生 inspect／verify／report 與一般 Codex 模型設定；草稿由開發者手動複製，人工確認綁定固定快照。

納入正式 1.4.0 資產的 Group／Repository 升級與回復驗證，保留使用者 Wiki、AGENTS.md、既有報告及個人 Skills。Extension 的唯讀狀態橋接可由安裝器的狀態依賴產生，避免另維護一份來源。
