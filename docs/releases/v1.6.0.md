# WorkflowKit 1.6.0

新增共用、離線的 Tree-sitter 語法導航，供 Codebase LLM Wiki、MergeReviewer 與 ReleaseReviewer 使用。上游儲存庫、原始 ZIP 與版本 pins 保持不變，增強透過可追溯的安裝版 overlay 提供。

- 支援 Windows x64、一般版 CPython 3.11–3.14，以及 C#、Java、JavaScript／JSX、TypeScript／TSX。官方 wheel 解壓資產、grammar、query、授權及 ABI 都有固定身分與 SHA-256，執行不需要 pip、npm、編譯器或網路。
- Reviewer 僅在原生固定快照完成後調整初始行段讀取；保留全部 diff、instructions、必要版本、merge-parent 與原生證據／報告驗證。完整成員、初始化與未讀範圍不代表已完成語意審查。
- Wiki 的來源分析分支在原生盤點後使用結構導航；一般 Query 維持 Wiki-first，NotebookLM 完整來源檢查及 DLP 保持原流程。
- 四種 Group／Repository × bundled／external BMAD 安裝組合保留更新、回退與使用者內容。未支援或無法可靠解析的來源沿用原讀取方式；未受管檔案與雜湊異常會回報安裝完整性錯誤。

**此版本預設 `WORKFLOW_KIT_SYNTAX_CONTEXT=off`。** 明確設為 `auto` 可供評估；模型品質、完整審查輸入量及總耗時尚未完成配對驗收，不能宣稱已達成 20% 輸入或 10% 耗時改善。

本機最終 29 項受影響回歸、四個 Python ABI 共 84 項測試通過。完整本機 release discovery 為 171 通過、2 skip、1 Wiki 圖表瀏覽器退出／暫存清理失敗；Chrome 與 Edge 重跑均重現，原生圖表驗證器未修改。詳見[完整驗證紀錄](../validation/tree-sitter-1.6.0.md)。正式附件另由版本提交的 GitHub Actions 完整矩陣驗證並發布，不能以本機紀錄替代 CI 證明。
