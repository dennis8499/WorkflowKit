# WorkflowKit 1.7.0

新增 MergeReviewer 與 ReleaseReviewer 的審查模型選擇。支援 `model-routing-model-selection` 的 GitLab 工作台可在建立審查前指定模型及思考強度；風險評估、正式審查與後續升級都沿用該模型。

- `ReviewModelRouting/v2` 保存所選模型、可用強度快照、建議與實際強度，以及固定來源、草稿、checkpoint 與歷程。恢復時拒絕更換模型、能力或固定證據。
- Auto 選擇達到風險建議的最低可用強度；超出模型上限時使用最高強度並保留原因，避免重複啟動同強度升級。無法排序的強度可手動指定，手動設定在同次審查中保持固定。
- 舊 v1 紀錄及未提供模型參數的直接 Skill 呼叫保留 GPT-6 Luna 協定。套件發行、installer API 1、status API 1 與 workspace contract 2 保持相容。
- 使用已發布的 1.6.0 原始附件建立可信升級來源，驗證 Group／Repository 與 bundled／external BMAD 四種組合的升級、重複安裝及回退，保留使用者設定、Wiki 與既有報告。

上游維持 Codebase LLM Wiki 0.7.2、MergeReviewer 0.20.6、ReleaseReviewer 0.12.0、CommitReviewer 0.1.0 與 BMAD Method 6.12.4。Tree-sitter 仍預設關閉，明確設定 `WORKFLOW_KIT_SYNTAX_CONTEXT=auto` 可進行評估。

模型選擇的歷史專項與實機驗收，以及當時的安裝逾時、瀏覽器清理及工作台測試限制，保留於 [2026-11-09 驗收紀錄](../validation/model-selection-20261109.json)。正式附件由最終版本提交的 GitHub Actions Windows／Python 3.11 與 3.14 完整矩陣驗證後發布。
