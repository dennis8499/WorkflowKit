# WorkflowKit 1.8.0

此版本整合 MergeReviewer 0.21.0，修正審查前後完成判定、報告渲染型別及操作進度，並加入帶雜湊核對的固定啟動請求與唯讀查詢路徑。

- 工作台可用 `ReviewLaunchRequest/v1` 固定 Repo、工作區、分支、request ID 與安裝綁定，避免模型重抄參數。請求與 launcher 身份都必須通過核對。
- 啟動先作唯讀 preflight；輸入錯誤不建立 native job。capabilities、摘要狀態與明確唯讀 view 不準備 scratch runtime。
- 依能力為新審查選 compact 草稿，既有 session 保留原格式。限制、未執行測試與必要缺口分開記錄；正式審查先補查可取得的證據，再如實發布確實受阻的未完成報告。
- 文件按預檢、評估、審查與恢復載入；checkpoint 保存操作、續讀、未解事項及下一步。模型沿用已保存選擇。

舊 `run.py -- <argv>`、routing v1/v2、歷史報告與收據保留相容性。未知渲染錯誤保留證據供診斷，不允許偷換工具身份接續發布。Syntax context 預設保持 off。

安裝與套件來源仍使用原有離線 hash／交易機制。實際驗證範圍、未完成門檻與重播方法見 [審查可靠性驗收](../reviewer-reliability.md)。遠端發行狀態與正式資產以 v1.8.0 GitHub Release 為準。
