# WorkflowKit 1.9.0

審查直接由目前 agent 執行，移除 Auto 判級、模型路由 Skill 與自動升級。GitLab 工作台選擇固定模型及強度；複製提示詞沿用 CLI 設定。歷史 routing 資料保留供固定設定續作，不重建快照。

內含 MergeReviewer 0.22.0：批次搜尋預抓遵循正式契約範圍，支援原子 compact 草稿與 checkpoint 保存、便宜的唯讀狀態摘要，以及相同 blob 正文共用。首次發布仍完整驗證固定證據。

唯讀 runner 支援已驗證 Merge helper 的 preflight 與 help，避免預檢先建立 scratch。安裝退役未修改的受管理 Router 檔案；使用者修改與舊收據保留。ReleaseReviewer 0.12.0 的原生行為保持相容。

本機測試、真實模型執行與效能門檻分別記錄於 [本輪驗收](../../validation/native-review-20261111.md)。未通過配對品質及時間門檻前，不宣稱端到端加速達標。
