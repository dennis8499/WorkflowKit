# Native reviewer execution

Run the requested native Reviewer in the current agent. Workbench model and effort
are fixed by the task; a copied prompt uses the current CLI settings.

1. Validate the supplied bound launch before loading authoring examples. Use the
   exact request, paths and runtime. An existing job resumes its fixed sources;
   a new Merge job selects advertised compact authoring.
2. Read the native Skill and its review rules. Read complete required changes,
   necessary versions and evidence-linked consumers. Load authoring and output
   examples when writing the draft. Use UTF-8 JSON files rather than shell-built
   JSON; preserve one-element arrays.
3. Save each semantic work unit. Merge's advertised `atomic_authoring` operation
   saves compact updates and a bounded checkpoint together. Release uses its
   native updates/progress interface. Helpers never supply semantic judgments.
4. Run native check, repair actionable authoring errors on the same request, then
   finish and verify the publication receipt. Publication and review completeness
   are separate: deliver genuine necessary gaps in the published outcome.

After interruption, inspect native status and its saved draft/checkpoint. Continue
unread pages and unfinished decisions; reconcile an older draft hash before using
its navigation notes. A helper response, saved artifact or ended model turn does
not prove publication or semantic completeness. Preserve cancellation and unknown
dispatch states. Already published reports are opened or cleaned up, not reviewed
again to reconcile an outdated conversational summary.
